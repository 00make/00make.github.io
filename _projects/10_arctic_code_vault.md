### 🧊 计划背景与全球永久封存

为了保存人类开源文明与现代软件智慧，GitHub 于 2020 年正式实施了 **GitHub Archive Program (北极代码宝藏计划)**。

GitHub 将全球活跃且有贡献的开源软件代码，使用由挪威 Piql 公司研发的特制感光长存胶卷（耐酸碱、抗辐射、寿命超 1000 年）进行离线光学编码转录，并将 21TB 的胶卷运往位于挪威北极圈内的斯瓦尔巴群岛（Svalbard），封存在一座深埋于地下千米废弃煤矿永冻土层中的北极世界档案馆（Arctic World Archive, AWA）。

### 📜 入选开源项目：BUCTBASE 校园开源知识库

- **开源初衷与共建**：
  - 在大学期间，为了解决广大同学在考试复习、课业资料获取、课程设计与代码参考时的痛点，张振尧在 GitHub 上主持创建并维护了面向北京化工大学的开源课程资料整理项目 **BUCTBASE**。
  - 平台汇集了计算机、机械、数学等多学科的开源代码、学习心得与开源学习笔记，吸引了大量校园开发者共同贡献与提 PR。
- **官方荣耀入选**：
  - **2020 年 7 月 8 日**，包括 BUCTBASE 以及张振尧名下主持贡献的开源项目，正式作为全球开源代码的组成部分，被 GitHub 官方永久存盘并运往北极永久冻土封存，获颁 GitHub Arctic Code Vault Contributor 官方终身荣誉勋章。
