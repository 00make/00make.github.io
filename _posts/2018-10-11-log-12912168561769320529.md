那天把在 MacBook 上安装及激活 Windows 的流程完整走了一遍，记录下来。

1. 下载 64 位非 geniouswin8 以上系统。
2. 用 BootCamp 助理制作 WIN10 启动 U 盘，并获取 Windows 对应的驱动。BootCamp 助理的位置在"应用程序—实用工具"下。
3. 选择第一个选项（制作 WIN10 U 盘启动）和第二个选项（获取 Windows 对应的驱动）。注意：其他分区和未分配的空间不要动，删除后 Mac OS 就崩溃了。
4. 删除后会出现相应页面，然后再点"应用"（大小默认的最大，不用自己调整）。Windows 主分区即完成，选择后点下一步，自动重启后就自动进入 WIN10。
5. 安装 Windows 对应的 BootCamp 驱动（驱动已经在 U 盘里），双击打开 BootCamp。
6. 安装驱动人生离线无线网卡驱动。
7. 安装各种驱动。
8. 打开 WIN10 激活工具，点击激活就 OK。
