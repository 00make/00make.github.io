项目

聚焦具身智能（VLA/机械臂/四足运控）、AI 智能体应用、边缘硬件与开源生态。

具身智能

单卡极限部署：80层 VLA 模型真机闭环

在单张 32GB RTX 5090 消费级显卡上跑通 80 层 Decoder 架构 VLA 模型（WALL-OSS）全链路微调 + LeRobot SO-101 机械臂真机闭环，端到端延迟低至 33–100ms。

robodog 与 AgentOS 机器人实时操作系统

机器狗高自由度运动控制库，结合 6 轴机械臂与 WebXR 空间交互，支持姿态估计、UWB 定位、自主避障与手势抓取。

“吹了么” (TRI.ME) — 模块化具身理容机械臂

基于七轴机械臂与视觉大模型，48 小时极限开发斩获小红书首届黑客松硬件赛道三等奖，受邀亮相 2026 世界人工智能大会 (WAIC) 公开展出，获人民网、解放日报·上观新闻、China Daily 专题报道。

AI应用与智能体

PCBTool AI — 基于 NVIDIA NIM 的电路设计智能体

运行于 NVIDIA NIM 微服务架构的 RAG 驱动电路设计智能体。入选英伟达展台优秀案例展示，并签署正式官方展示授权。

边缘智能与嵌入式

“土豆子”边缘 AI 伴侣与量产硬件

基于 xiaozhi-esp32-server 的低延迟端侧语音与 LLM 边缘交互硬件方案，实现 500+ 台整机硬件量产与结构/固件全流程交付。

dmcan 电机控制库与 ROS 动力学集成

封装达妙（DM）无刷电机 CAN 总线力矩与阻抗控制算法，构建基于 ROS/ROS2 的分布式实时驱动框架。

开源生态与创业

treehollow 校园社交平台与开源社区

主导开发的校园匿名开源社交平台，覆盖全国 34 所高校，日活跃用户超 10 万+。

农村住房安全管理系统 (屋必安)

带领零零后科技独立自研并在多地政府落地，服务脱贫攻坚与危房动态清零，获挑战杯市级二等奖、国家级大创一等奖及多项计算机软件著作权。

医疗虚拟现实手术模拟训练系统研发

在北京众绘担任创新研发总监期间，主导 5 款医疗模拟软硬件产品研发，年营收突破 2000 万元，申请 5 项发明专利。

GitHub Arctic Code Vault (北极代码宝藏计划)
